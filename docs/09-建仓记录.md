3. **仓库改为公开**：因仓库内只有脚手架、文档与需求说明，无密钥与个人信息（`configs/*.yaml` 已检索无 password/secret/token 字样），且题面要求教师可访问，故将仓库改为 Public（API PATCH 成功）。
4. **规则改为 API 下发并开启 `enforce_admins=true`**，再次实测直推被拒：


5. **规则读取结果**（API GET 成功）：`enforce_admins=True`、`allow_force_pushes=False`、`allow_deletions=False`、`required_pull_request_reviews` 存在（required approvals = 0，本人可合并自己的 PR）。
