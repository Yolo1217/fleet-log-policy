# 题目 09 任务清单（任务编号 ↔ 需求条目）

> 依据：`docs/09-需求分析.md`（规则 1～8、边界 1～15、五场景）、`docs/09-原型.md`。
> 状态说明：本清单在开发前制定，全部任务初始为「待做」；完成情况随实际提交更新，不得预先勾选。
> 工作项编号：`feat` 提交需真实飞书需求编号并在提交前用 meegle CLI 核验；当前尚未分配，标注为「待教师分配」。

## 1. 依赖与约定

- 技术栈沿用脚手架：Gin gateway → service → repo → SQLite（Gorm），proto 可选。
- 时间边界统一用教学时钟（`configs` 可配置超时秒数，默认 60）。
- 每台车独立版本号，`expected` 与 `applied` 分字段存储；异常写 `exception_record` 表。
